# Biseda

Lista bisedash, dërgim mesazhesh dhe përgjigje automatike — si WhatsApp, por demo lokale.

## Veçori

- 💬 **4 kontakte** — avatar me iniciale, mesazhi i fundit, ora, badge të palexuarash
- 🔍 **Kërkim** — filtrim kontakteshi në kohë reale
- 🟢 **Statusi online** — me pikë jeshile në header-in e bisedës
- 💭 **Flluska mesazhesh** — të miat djathtas (gold), të marra majtas, ora nën çdo flluskë
- ⌨️ **Enter për dërgim** + indikator "po shkruan…" para përgjigjes
- 🤖 **Bot shqip** — përgjigje të ndryshme sipas kontaktit dhe fjalëve kyçe (përshëndetje, si je, ok, faleminderit…)
- 💾 **localStorage** — mesazhet ruhen mes sesioneve
- 📱 **Responsive** — në mobile sidebar bëhet listë me buton kthimi ←
- 💻 **Kodi burim** — tabs HTML/CSS/JS me kopjim, direkt në faqe
